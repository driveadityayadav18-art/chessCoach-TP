# Aditya Yadav — Master Chess Mentorship

An elite, high-craft editorial chess coaching platform built with Next.js 15, React 19, Tailwind CSS, Three.js / React Three Fiber (3D Staunton Rook), and Framer Motion.

---

## Key Features

- **Interactive 3D Staunton Rook**: Custom WebGL 3D piece animation dynamically traversing the page narrative using `@react-three/fiber` and `@react-three/drei`.
- **Grandmaster Chessboard Showcase**: Interactive 8x8 analytical board with real master positions (Carlsbad Minority Attack, Kotov Calculation Tree, Lucena Bridge, Prophylaxis) featuring Framer Motion spring sliding pill controls and audio piece placement.
- **Architectural Editorial System**: Custom typography scale featuring Cormorant Garamond, Plus Jakarta Sans, and Geist Mono, with tactile drafting table crosshairs (`+`) and 21st.dev luminous border beams.
- **Architectural Studio Footer**: Live New Delhi local time clock (IST), real-time cohort capacity tracker, and monumental typographic signature watermark.
- **Booking & Diagnostic Evaluation Flow**: Accessible modal dialogue connecting to diagnostic consultation scheduling.

---

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Custom Properties
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: Framer Motion (`motion/react`)
- **Fonts**: Google Fonts (`Cormorant Garamond`, `Plus Jakarta Sans`, `Geist Mono`)

## Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm or pnpm or yarn

### Installation

1. Navigate to the `chesscoach` directory:
   ```bash
   cd chesscoach
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build

To build and verify the optimized production build:
```bash
npm run build
npm start
```
